# RIDDANCE

> Remove Weakness. Build Discipline.

RIDDANCE is a full-stack TypeScript application designed to help users build discipline by tracking physical, mental, and spiritual habits.

## Features

- 🏃 Strava Integration
- 💪 Workout Tracking
- 🧘 Meditation
- 📖 Bible Reading
- 📝 Journaling
- 📊 Analytics
- 🔥 Streaks
- 🤖 AI Coaching (planned)

## Tech Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- DaisyUI

### Backend

- Node.js
- Express
- TypeScript
- Prisma
- PostgreSQL
